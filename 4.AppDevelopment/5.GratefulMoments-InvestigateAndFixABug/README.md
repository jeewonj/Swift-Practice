# Grateful Moments: Investigate and fix a bug

Learn to resolve bugs with unit tests and the Xcode debugger.

Even with thorough testing, issues can surface as more people use your app.

## Overview

These resources are associated with the [Investigate and fix a bug](https://developer.apple.com/tutorials/develop-in-swift/investigate-and-fix-a-bug) tutorial. This is part of the [App Development](https://developer.apple.com/tutorials/develop-in-swift/welcome-to-app-development) tutorials from [Develop in Swift](https://developer.apple.com/tutorials/develop-in-swift) by Apple.

## Using these resources

Follow the tutorial instructions in section one of [Investigate and fix a bug](https://developer.apple.com/tutorials/develop-in-swift/investigate-and-fix-a-bug) to use these resources within the Xcode app.
